# ft_traceroute

A from-scratch implementation of the `traceroute` command in C. This diagnostic tool traces the route that packets take to reach a network host, providing valuable insights into network topology and routing delays.

## 🛠️ Technical Stack & Concepts
* **Language:** C
* **Networking:** Raw Sockets, Manipulating IP Headers
* **Protocols:** UDP, ICMP (Time Exceeded, Destination Unreachable)
* **Key Skills:** TTL (Time-to-Live) manipulation, precise timeout handling, byte-order conversion.

## 🚀 Usage

Compile the project:
```bash
make
